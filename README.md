# nico-extension

ニコニコ動画の動画を、公式プレイヤーの代わりに `nicovideo.jp` のページの上のオーバーレイで再生する Chrome 拡張（Manifest V3・WXT・TypeScript）。

- Chrome 123 以上専用。Firefox には対応しない。
- ニコニコ動画にログインした状態で使う。ブラウザの Cookie をそのまま使う。未ログインでも再生とコメントの表示はできるが、投稿とニコるはできない。
- 非公開。パッケージ化されていない拡張として読み込む。
- 動画のセグメントは保存しない。
- 対象外: `nicovideo.jp` 以外のサイトでの再生、連続再生（マイリスト・プレイリスト）、シークバーのサムネイル、公式の NG 設定との同期、拡張独自の NG リスト、かんたんコメントの投稿。

機能と状態の一覧は [docs/spec/extension/requirements.md](docs/spec/extension/requirements.md)。

## ビルド

Node と pnpm のバージョンは `mise.toml` で決まる。

```sh
mise install
mise exec -- pnpm install
mise exec -- pnpm build
```

出力は `.output/chrome-mv3`。

## 読み込み

1. `chrome://extensions` で「デベロッパー モード」を有効にする。
1. 「パッケージ化されていない拡張機能を読み込む」で `.output/chrome-mv3` を選ぶ。

- 別のマシンでビルドしたときは、`.output/chrome-mv3` を Chrome のあるマシンの決まったフォルダにコピーして読み込む。読み込むフォルダを変えると拡張の ID が変わり、設定を引き継がない。
- 更新したら、`chrome://extensions` で拡張を再読み込みし、nicovideo.jp のタブも再読み込みする。
- Dark Reader などの色を書き換える拡張は、オーバーレイの色を崩すことがある。nicovideo.jp を対象外にする。

## 使い方

### 開き方

- `nicovideo.jp` 内の動画リンク（`/watch/sm…`・`/watch/nm…`・`/watch/so…`）をクリックすると、画面遷移せずにオーバーレイで開く。閉じると元のページに戻る。
- `/watch/{動画 ID}` を直接開いたとき（アドレスバー、ブックマーク、外部サイトのリンク、Ctrl・中クリックで開いた新しいタブ）もオーバーレイで開く。閉じると前のページ（なければトップページ）に移る。
- 上段の右端の「公式で開く」で、公式プレイヤーで開き直す。URL に `?nico-ext=off` を付けると、公式プレイヤーで開く。
- 閉じるのは ✕ か Esc。
- 開いた動画のリンクは訪問済みの見た目になる。

### 画面

- 上段: タイトル、投稿日時、再生・コメント・マイリスト・いいねの数、タグ。右端にテーマの切り替え（ライト・ダーク・OS の設定に合わせる）、「公式で開く」、✕。
- 左: 動画、シークバー、コントロールのバー、投稿欄。シークバーの帯はコメントの盛り上がりを虹色で示し、キャッシュ済みの範囲を太く示す。
- 右パネル（画面の幅が 900px 以下では動画の下）: タブで切り替える。

| タブ | 内容 |
| --- | --- |
| 動画の詳細 | 投稿者、ジャンル、シリーズ（前・次の動画）、説明文 |
| コメント | コメント一覧。時刻のクリックでその位置へ移る。各行のボタンでニコる・取り消す。「自動スクロール」で再生位置への追従を切り替える |
| 設定 | 共有 NG レベル（無・弱・中・強）、シークバーの盛り上がり（表示・隠す、強調） |

### キーボード

| キー | 動作 |
| --- | --- |
| Space / K | 再生・一時停止 |
| ← / → | 5 秒戻る・進む |
| J / L | 10 秒戻る・進む |
| ↑ / ↓ | 音量 ±5% |
| M | ミュート |
| C | コメントの表示・非表示 |
| H | コントロールを動画に重ねる・動画の下に置く |
| F | 全画面 |
| < / > | 再生速度を 1 段階下げる・上げる |
| 0〜9 | 動画の 0〜90% の位置へ |
| Home / End | 先頭・末尾へ |
| Enter | コメントの入力欄に移る |
| Esc | 閉じる（全画面中はブラウザが全画面を解除する） |

入力欄と設定のスライダーではキーをそのまま使い、Esc でそこから抜ける。

### マウス

| 操作 | 動作 |
| --- | --- |
| 動画のクリック | 再生・一時停止 |
| 動画のダブルクリック | 全画面 |
| ホイール | 音量 ±5%（上で上げる） |
| Shift + ホイール | 5 秒進む・戻る（上で進む） |
| Ctrl + ホイール | 再生速度を 1 段階上げる・下げる（上で上げる） |

右パネルの上のホイールはパネルのスクロールに使う。

### コメントの投稿

投稿欄のコマンド欄（空白区切り）と本文に入れ、Enter か「コメント」ボタンで今の再生位置に投稿する。自分の投稿は黄色の枠で囲んで流す。確認（Cloudflare Turnstile）を求められたときは、「公式で開く」から公式プレイヤーで投稿する。

## 既知の制約

- WebGL2 が使えないとコメントが流れない（一覧は出る）。`chrome://gpu` の「WebGL2」で確かめられる。
- GPU のリセットやスリープからの復帰でコメントが消えたときは、オーバーレイを開き直すかページを再読み込みする。
- 公式の watch ページ（`?nico-ext=off`）の上でリンクから開くと、公式プレイヤーも動き続ける。
- nicovideo.jp 内の JS による画面遷移（リンクのクリックでない遷移）で watch ページに移ると、公式プレイヤーになる。
- `/watch/{数字}`（チャンネル動画のスレッド ID の形式）は対象外。
- `?from=秒` などの開始位置の指定は読まない。
- 自動再生がブラウザに止められたときは、一時停止のまま開く。

ほかの制約は [docs/spec/extension/behavior.md](docs/spec/extension/behavior.md#制約)。

## 開発

- 仕様書は [docs/spec/](docs/spec/README.md)。機能の追加・変更は、仕様書を先に直してから実装する（[変更の流れ](docs/spec/README.md#変更の流れ)）。
- 型チェックは `mise exec -- pnpm compile`。
- 動作は、拡張を読み込んだ headless Chromium で動かすプローブ（`scripts/*_probe.py`）で確かめる（[docs/spec/extension/testing.md](docs/spec/extension/testing.md)）。
