# 動作

## 起動

### リンクのクリック

- `document` の capture フェーズで、`www.nicovideo.jp/watch/{sm|nm|so}{数字}` へのリンクのクリック（左ボタン、修飾キーなし）を奪い、URL を変えずにオーバーレイを開く。クエリ（`?ref=…`）付きのリンクも対象。
- Ctrl・Shift・中クリックなどはブラウザに任せる（新しいタブでは[直接開く](#直接開く)の動作になる）。
- 閉じると（✕・Esc）オーバーレイを消して元のページに戻る。
- オーバーレイ内の動画リンク（説明文の動画、シリーズの前後）は、オーバーレイでその動画に切り替える。それ以外のリンク（タグ・投稿者・シリーズ・外部）は新しいタブで開く。

- **確かめ方**: `ext_probe.py` の `url unchanged: True`、`video:` で `t` が進み `rs` が 4、`closed: True`、`reopened:` で再生。オーバーレイ内の動画リンク（シリーズの「次」）は実機の Chrome で見る。

### 直接開く

`/watch/{id}` をページ遷移で開いたとき（アドレスバー、ブックマーク、外部サイトのリンク、新しいタブ）も自作プレイヤーで開く。

1. 静的な declarativeNetRequest の規則（`public/rules.json`）で、`main_frame` の `https://www.nicovideo.jp/watch/{sm|nm|so}{数字}` を `/nico-ext/watch/{id}` にリダイレクトする（存在しないページ = 404 ページ）。クエリは引き継ぐ。
1. クエリに `nico-ext=off` を含む URL は、優先度の高い `allow` の規則でリダイレクトしない。
1. content script はパスが `/nico-ext/watch/{id}` なら、`history.replaceState` でアドレスバーを `/watch/{id}{クエリ}` に戻してオーバーレイを開く。タブのタイトルを `{動画タイトル} - ニコニコ動画` にする。
1. 閉じると履歴を戻る。`history.length` が 1 か、300ms 以内に `beforeunload` が来なければトップページへ `location.replace` する。オーバーレイは消さずに離れ、視聴イベントの `end` は `pagehide` で `keepalive` の fetch で送る。
1. オーバーレイ内の動画リンクは、そのリンクの URL へ移る。

- **確かめ方**: `direct_probe.py` の 4 つの場面（Ctrl+クリックの新しいタブ、トップページからの遷移、戻る先がない位置、外部ページからの遷移）で `overlay: True`・`t` が進む・アドレスバーが `/watch/{id}`、閉じたあとの `url` が期待どおり（トップページか元のページ）。

### 公式で開く

上段の右端の「公式で開く」で `/watch/{id}?nico-ext=off` へ移る。直接開いたときは `location.replace`、リンクから開いたときは `location.assign`。

- **確かめ方**: `direct_probe.py` の「公式で開く」で `overlay: False`・`officialVideo: True`、戻ると外部ページ。

### 訪問済みにする

オーバーレイを開くとき、`history.replaceState` で URL を `https://www.nicovideo.jp/watch/{id}` とクリックしたリンクの URL に書き換えてすぐ戻し、両方の URL を訪問済み（`:visited`）にする。履歴の項目は増えず、`popstate` も起きない。

- **確かめ方**: `visited_probe.py`。開いた動画のリンクの文字色が `(70, 70, 70)` → `(192, 192, 192)`、開いていない動画は変わらない。`url unchanged: True`・`history unchanged: True`。

### v4 の検知

watch ページの `server-response` が [v4](../niconico/watch-page.md#v4) のとき、オーバーレイに「ニコニコ動画の視聴の仕組みが変わりました。拡張の更新が必要です。「公式で開く」で再生できます」と出し、再生しない。console に `[nico-ext] watch api v4 detected` を出す。再生中にトークンを取り直したときに v4 だった場合も、同じ文を出す。

- **確かめ方**: 使い捨てのスクリプトで、watch ページの応答の `server-response` を `{"meta":{"status":200},"data":{"response":{"$watchV4":{"data":{}}}}}` に差し替え、リンクを差し込んでクリックし、`.message` の文字と console を見る。差し替えないときは `ext_probe.py` が今までどおり通る。

## 画面

### オーバーレイ

- `createShadowRootUi`（`position: 'modal'`、`isolateEvents: true`）。外枠（`container`）に `z-index: 2147483647` を付ける。
- 背景は不透明で、画面の端から 16px 内側の全面。

- **確かめ方**: `ext_probe.py` の `covered by others: []`（オーバーレイの上に出るページの要素がない）。

### 配置

- 上段（全幅）: タイトル（1 行、省略記号つき、クリックで[動画名のコピー](#動画名のコピー)）、投稿日時と再生・コメント・マイリストの数、タグ（ロックされたタグに鍵のアイコン、はみ出すタグは薄くして隠す）。右端にテーマの切り替え・「公式で開く」・✕。
- その下の左に動画とコントロール、右にパネル。パネルの上端に[いいね！の欄](#いいね)、その下にタブ。
- 動画の枠を動画の縦横比（`videoWidth` / `videoHeight`、読み込み前は 16:9）に合わせる。横に余った幅はパネル（320〜480px）に回し、それでも余る分は左右の余白にして中央に寄せる。縦に余った分は、コントロールを動画のすぐ下に付けて、その下を背景にする。
- 画面の幅が 900px 以下では、パネルを動画の下（画面の高さの 30% 以上）に置く。
- 全画面は動画とコントロールの枠（`.player`）に対して行い、画面全体に広げる。

- **確かめ方**: `layout_probe.py` の画面の大きさ 6 種で、`barsX`・`barsY`（黒い帯）が 0、`overflow` が 0 以下、`panel` が 320〜480、860×900 で `narrow: True`。`ext_probe.py` の `layout:` でタイトルとタグの数。

### 動画名のコピー

上段のタイトルをクリックすると、動画名と URL を Markdown のリンクの形でクリップボードにコピーする。

```markdown
[動画名](https://www.nicovideo.jp/watch/sm46878133)
```

- URL は `https://www.nicovideo.jp/watch/{id}`（クエリなし）。
- 動画名の `\`・`[`・`]` は前に `\` を付ける。
- コピーできたら OSD に「リンクをコピーしました」、できなかったら「リンクをコピーできませんでした」を出す。
- タイトルのカーソルはポインター。`title` は動画名と「クリックで Markdown のリンクをコピー」の 2 行。

- **確かめ方**: `title_probe.py`（クリップボードの書き込みを許可してタイトルを押すと、クリップボードの文字が watch ページの動画名から作ったリンクと一致し、OSD が「リンクをコピーしました」。CDP の `Browser.setPermission` で書き込みを拒んで押すと、OSD が「リンクをコピーできませんでした」）。

### コントロール

- 動画の下に、シークバー、コントロールのバー（再生、ミュートと音量、時間、コメントの表示、再生速度、画質、コントロールの固定、全画面）、投稿欄を置く。
- H キーかバーのボタンで、動画に重ねて 2.5 秒操作がないと隠す表示に切り替わる。重ねる表示でも、停止中とコントロール内にフォーカスがある間は隠さない。
- 音量・位置・速度などを変えると、動画の上部に値を 1.5 秒出す（OSD）。投稿・ニコる・いいね！の失敗も OSD に出す。
- 動画のクリックで再生・一時停止、ダブルクリックで全画面。
- 再生速度は 0.5・0.75・1・1.25・1.5・1.75・2 倍。
- 画質は「自動（再生中の画質）」と各画質。

- **確かめ方**: `ext_probe.py` の `layout after h`（`pinned: False`）、`layout after idle`（`controlsOpacity` が 0）、`layout after h again`（`controlsBelowVideo: True`）、`quality lowest:`（`h` が最も低い画質）。`post_probe.py` の `unpinned, focused, idle` で `controlsOpacity` が 1。

### シークバー

- 細い帯（4px）、キャッシュ済みの範囲だけを見せる太い帯（10px）、透明な `input[type=range]` の 3 層。再生位置は白い 16×16 の四角のつまみ。
- 盛り上がりを表示するとき、帯を虹色（青・水色・緑・黄・橙・赤、OKLCH で補間）にする。
    - `voltageZone.heatmap`（20 区間）を、区間内の一般のコメント（投稿者コメントを除く）の `vposMs` の件数の比で 200 区間に振り分ける。各区間に平均の件数を足し、前後 3 区間と平滑化する。`heatmap` の最大を 1 とし、1 を超える分は 1。
    - その値を「強調」乗（1.0〜4.0、既定 2.0）してから色に当てる。
- 盛り上がりを隠したときは、再生済みが青、キャッシュ済みが灰（`#666`）、それ以外が暗い灰（`#333`）。

- **確かめ方**: `heatmap_probe.py`。`argmax same True`・`argmin same True`、帯の太さ 10 / 4、設定タブの表示・隠すが `ok`、強調の変更で `video unchanged True`、開き直して設定が残る。

### 前回の再生位置

- 開いたとき、その動画の記録があれば、シークバーの記録の位置に印を出す。印は開いたときの位置から動かさない。
- 開いたときの再生の位置は、[URL の再生位置](#url-の再生位置)があればその位置。なければ、設定タブの「開いたとき」が「先頭から」（既定）なら先頭、「前回の位置から」なら記録の位置。記録がなければ先頭。
- 印は白い縦棒（幅 2px、シークバーの高さ）と、その下に接する白い ▲（幅 8px、高さ 6px）。どちらも黒い 1px の縁。▲ はシークバーの下にはみ出す。ホバーで「前回 {時刻}」を出し、縦棒か ▲ のクリックでその位置へ移る。
- 記録は動画 ID ごとの位置（秒、整数に切り捨て）と記録した日時。ニコニコには送らない。
    - 再生中は 5 秒おき、一時停止したとき、閉じたとき、ページを離れるとき（`pagehide`）に書く。
    - 開いてから再生していた時間の合計が 3 秒に満たないうちは書かず、前の記録を残す。
    - `ended` でその動画の記録を消す。
    - 書いたあとに 1,000 件を超えたら、記録した日時の古いものから消す。
- 設定タブの「前回の再生位置」に、「開いたとき」（先頭から・前回の位置から）、記録の件数と「すべて消す」のボタンを置く。「すべて消す」を押すと記録をすべて消し、開いている動画の印も消す。

- **確かめ方**: `resume_probe.py`。
    - 60 秒へ移して 10 秒再生し、一時停止して閉じる。開き直すと `currentTime` が 1 秒未満、印の位置が記録の秒数 / 長さ、`title` が「前回 1:10」前後。印のクリックで `currentTime` が記録の秒数。
    - 開いて 2 秒再生して閉じても、記録が変わらない。
    - リンクのクリックで開き、150 秒へ移して 11 秒再生して ✕ で閉じると、記録が 160 秒前後。
    - 末尾へ移して `ended` のあと開き直すと、印が出ない。
    - 1,000 件の記録がある状態で別の動画を記録すると、1,000 件のまま最も古い記録が消える。
    - 「すべて消す」で件数が 0 になり、印が消える。
    - 「前回の位置から」を選んで開き直すと、`currentTime` が記録の秒数から始まる。開き直しても選択が残る。

### URL の再生位置

開いた URL のクエリの `from`（[URL の再生位置](../niconico/watch-page.md#url-の再生位置)）の秒数から再生する。

```text
https://www.nicovideo.jp/watch/sm39244189?from=400&ref=my_nicoru_passive
```

- 読む URL は、リンクのクリック（オーバーレイ内の動画リンクを含む）ではリンクの URL、[直接開く](#直接開く)ではページの URL。
- `from` の値が `400`・`12.5` のような 0 以上の数なら、小数を切り捨てた秒数にする。それ以外の値（`1:23`・`-5`・`400s` など）と、`video.duration` 以上の値は読まない。
- 前回の再生位置の設定（「開いたとき」）より優先する。`from=0` は先頭から再生する。
- 前回の再生位置の印は、`from` によらず記録の位置に出す。

- **確かめ方**: `resume_probe.py`。
    - リンクの URL に `?from=30` を付けて開くと、「開いたとき」が「先頭から」でも「前回の位置から」（記録 70 秒）でも `currentTime` が 30 秒から始まり、印は記録の位置。
    - `?from=12.5` で 12 秒、`?from=0` で「前回の位置から」でも先頭、`?from=1:23` と動画の長さ以上の値で `from` がないときと同じ位置。
    - 直接開いた `/watch/{id}?from=30` で `currentTime` が 30 秒から始まる。

### 右パネル

上端の[いいね！の欄](#いいね)の下に、タブで切り替える中身を置く。開いたときは常に「動画の詳細」。

| タブ | 内容 |
| --- | --- |
| 動画の詳細 | 投稿者（ユーザーかチャンネル）、ジャンル（未設定なら出さない）、シリーズ（前・次の動画）、説明文 |
| コメント（件数） | コメント一覧。タブの右端に「自動スクロール」 |
| 設定 | 共有 NG レベル（無・弱・中・強）、シークバーの盛り上がり（表示・隠す、強調）、[前回の再生位置](#前回の再生位置)（開いたときの位置、件数、すべて消す） |

- 説明文の HTML は `a`・`b`・`br`・`div`・`em`・`font`・`i`・`p`・`s`・`span`・`strong`・`u` だけで組み直す。属性は `a` の http(s) の `href` と `font` の `color` だけを移す。`a.seekTime` は[説明文の再生位置](#説明文の再生位置)のボタンにする。
- コメント一覧
    - owner・main・easy を `vposMs` 順（同じなら `no` 順）に 1 行ずつ並べる。時刻のクリックでその位置へ移る。
    - 再生位置以前の最後の行に印を付け、一覧の下端に合わせてスクロールする。マウスが一覧の上にある間と「自動スクロール」がオフのときはスクロールしない。
    - 自分の投稿は黄色の縦線と薄い黄色の背景、投稿者コメントは太字。
    - 各行のニコるのボタンに件数を出し、自分がニコったものは色を変える。押すとニコる・取り消す（[nvcomment.md](../niconico/nvcomment.md#ニコる)）。
- 共有 NG レベルで隠したコメントは、流すコメントと一覧の両方から除く。コメントタブの件数は表示する件数で、タブの `title` に隠した件数を出す。`isDisabled` の動画では設定タブに「この動画では共有 NG レベルは使われません。」と出す。
- パネル上のホイールはスクロールに使い、音量を変えない。

- **確かめ方**: `list_probe.py`（一覧の件数・並び・追従・時刻のクリック・ホバー中の停止・自動スクロールのオフと復元・未ログインでニコるが無効・開いたときは「動画の詳細」）、`ng_probe.py`（レベルごとの件数が `ok`）、`ext_probe.py` の `wheel on panel keeps volume: True`。説明文の表示、ニコる・取り消しは実機の Chromeで見る。

### 説明文の再生位置

説明文の再生位置（[`a.seekTime`](../niconico/watch-page.md#説明文の再生位置)）を、同じ文字のボタンにする。

- `data-seektime` が `m:ss`・`h:mm:ss` の形なら、押すと `currentTime` をその秒数にする。再生・一時停止の状態は変えない。
- `data-seektime` が読めない `a.seekTime` は文字だけにする。
- ボタンはリンクと同じ色で、`title` は「この位置へ移動」。

- **確かめ方**: `description_probe.py`（ボタンの数と秒数が `data-seektime` と一致、`href` が `#` のリンクが残らない、押すと `t` がその秒数で一時停止のまま、再生中に押すと再生が続く）。見た目は実機の Chrome で見る。

### いいね

右パネルのタブの見出しの上に、タブによらず同じ欄を置く。欄の高さは状態によらず同じ（ボタンの 1 行とメッセージの 3 行）。

- 1 行目はいいね！のボタンと数。いいね！した動画は色を変えて `aria-pressed="true"` にする。
- 押すと、いいね！していなければいいね！し、していれば取り消す（[like.md](../niconico/like.md)）。成功したら数を 1 増やす・減らす。送っている間はボタンを無効にする。
- 開いたときの状態は `server-response` の `video.viewer.like.isLiked` と `video.count.like`（[watch-page.md](../niconico/watch-page.md#使う値)）。ほかのタブ・公式での変更には追従しない。
- 失敗したら OSD に「「いいね！」に失敗しました ({errorCode か HTTP の状態})」（取り消しは「「いいね！」の取り消しに失敗しました (…)」）と出し、状態と数を変えない。
- 2 行目からはお礼メッセージの欄。本文はテキストとして出し、改行を保つ。3 行を超えたら欄の中でスクロールする。

| 状態 | お礼メッセージの欄 |
| --- | --- |
| 動画の読み込み中 | 空（ボタンを無効にし、数を出さない） |
| 未ログイン | 「ログインすると「いいね！」できます」（ボタンを無効にし、`title` にも同じ文を出す） |
| いいね！していない | 「いいね！すると、お礼メッセージがあればここに出ます」 |
| いいね！済みの動画を開いた（投稿者がユーザー） | 「読み込み中…」のあと、お礼メッセージを取得して出す |
| いいね！済みの動画を開いた（チャンネル） | 「お礼メッセージはありません」 |
| いいね！した | `POST` の応答のお礼メッセージ |
| お礼メッセージがない | 「お礼メッセージはありません」 |
| お礼メッセージの取得に失敗した | 「お礼メッセージを読み込めませんでした」 |
| 取り消した | 「いいね！していない」と同じ |

状態の文は薄い色で出す。画面の幅が 900px 以下では、お礼メッセージの欄を 1 行にして省略記号を付け、欄のクリックで 3 行の表示と切り替える。

- **確かめ方**: `ext_probe.py` の `layout:` の `like`（未ログインで `disabled: True`、`pressed: "false"`、`title` と欄の文が「ログインすると「いいね！」できます」）。`layout_probe.py` の画面の大きさ 6 種で `overflow` が 0 以下。いいね！・取り消し・数の増減・お礼メッセージ・失敗の OSD は実機の Chrome で行い、console の `[nico-ext] like: …` を見る。公式の watch ページ（`?nico-ext=off`）を開き直して状態が一致することを見る。

### 投稿欄

- コマンド欄（空白区切り）、本文、「コメント」ボタン。Enter で今の再生位置に投稿し、投稿のあとはコメントを取り直す。
- 投稿できないときは無効にして、本文の欄に理由を出す（[nvcomment.md](../niconico/nvcomment.md#投稿)）。
- 自分の投稿は、流すコメントで黄色の枠で囲む。

- **確かめ方**: `post_probe.py`（未ログインで `disabled: True` と理由、`typed` で入力欄に `kj m f 0` が入り再生状態が変わらない、`escape` でフォーカスが外れる）。投稿と黄色の枠は実機の Chromeで `sm27201969` に投稿して見る。

### テーマ

- ライト・ダーク・OS の設定に合わせるの 3 つ。既定は OS の設定に合わせる。
- `.backdrop` の `data-theme`（`light`・`dark`、OS に合わせるときは付けない）と `color-scheme` で決まり、色は `light-dark()` で書く。`.player` の中はテーマによらず `color-scheme: dark`。

- **確かめ方**: `layout_probe.py` の `== テーマ` の 6 状態で、背景が OS の設定・選んだテーマのとおり（ライト `rgb(242, 242, 242)`、ダーク `rgb(13, 13, 13)`）、`reopened` で選んだテーマが残る。

## 操作

### キーボード

オーバーレイを開いている間は、`window` の capture でキーを受けてページに渡さない。Ctrl・Meta・Alt 付きのキーはショートカットにしない。

| キー | 動作 |
| --- | --- |
| Space / K | 再生・一時停止 |
| ← / → | 5 秒戻る・進む |
| J / L | 10 秒戻る・進む |
| ↑ / ↓ | 音量 ±5% |
| M | ミュート |
| C | コメントの表示・非表示 |
| H | コントロールを動画に重ねる・動画の下に置く |
| F | 全画面 |
| < / > | 再生速度を 1 段階下げる・上げる |
| 0〜9 | 動画の 0〜90% の位置へ |
| Home / End | 先頭・末尾へ |
| Enter | コメントの入力欄に移る |
| Esc | 閉じる（全画面中はブラウザが全画面を解除する） |

- `shortcuts.ts` の `playerShortcuts` は、Esc を除いてこの表のとおりに定義する。
- 入力欄（`type=text`）と設定のスライダーでは、キーをそのまま使う。Esc でそこから抜ける。

- **確かめ方**: `ext_probe.py` の `keys …` の各行（C でコメントが `hidden`、→ で `t` が 10 秒進む、M でミュート、`>` で速度が上がる、↓ で音量が下がる、Space で一時停止と再生）。入力欄での動作は `post_probe.py`。

### ホイール

オーバーレイ全体（右パネルを除く）で受け、ページのスクロールと Ctrl+ホイールの拡大を止める。50px ぶんの移動で 1 段階。

| 操作 | 動作 |
| --- | --- |
| ホイール | 音量 ±5%（上で上げる） |
| Shift + ホイール | 5 秒進む・戻る（上で進む） |
| Ctrl + ホイール | 再生速度を 1 段階上げる・下げる（上で上げる） |

- **確かめ方**: `ext_probe.py` の `wheel …` の各行（修飾キーなし・Shift・Ctrl で音量・位置・速度が変わり、OSD に値が出る）。

## storage.local のキー

| キー | 値 | 既定 | 変える場所 |
| --- | --- | --- | --- |
| `local:player` | `{volume, muted, playbackRate, quality}`（`quality` は `'auto'` か高さの上限） | `{1, false, 1, 'auto'}` | コントロール、キー、ホイール |
| `local:comments` | `{visible}` | `{visible: true}` | C、コントロールのボタン |
| `local:layout` | `{controlsPinned}` | `{controlsPinned: true}` | H、コントロールのボタン |
| `local:commentList` | `{follow}` | `{follow: true}` | 「自動スクロール」 |
| `local:ngScore` | `'none'`・`'low'`・`'middle'`・`'high'` | `'middle'` | 設定タブ |
| `local:seekHeatmap` | 真偽値 | `true` | 設定タブ |
| `local:seekHeatmapGamma` | 1.0〜4.0 | `2` | 設定タブの「強調」 |
| `local:theme` | `'auto'`・`'light'`・`'dark'` | `'auto'` | 上段の右端 |
| `local:resume` | `{[動画 ID]: {sec, at}}`（`at` は記録した日時の ms） | `{}` | 再生、設定タブの「すべて消す」 |
| `local:resumeStart` | `'head'`・`'resume'` | `'head'` | 設定タブの「開いたとき」 |

`local:player` 以外は、ほかのタブでの変更にも追従する。`local:resume` で追従するのは設定タブの件数だけで、印は開いたときの記録のまま。

- **確かめ方**: `ext_probe.py` の `reopened:`（音量・速度・画質・コメントの表示）、`list_probe.py`・`ng_probe.py`・`heatmap_probe.py`・`layout_probe.py` の開き直したあとの値。

## 制約

- WebGL2 が使えないとコメントが流れない（一覧は出る）。ハードウェアアクセラレーションがオフ、GPU やドライバが Chrome のブロックリストに載っている、GPU のない仮想マシン、GPU プロセスが繰り返し落ちた、ポリシーや `--disable-gpu` で無効、の場合。`chrome://gpu` の「WebGL2」で確かめられる。
- WebGL のコンテキストが失われると（ドライバの更新、GPU のリセット、スリープからの復帰など）コメントが消える。オーバーレイを開き直すかページを再読み込みすると戻る。
- 公式の watch ページ（`?nico-ext=off`）の上でリンクから開くと公式プレイヤーも動き、HLS の取得と視聴イベントが二重になる。
- nicovideo.jp 内の JS による画面遷移（リンクのクリックでない遷移）で watch ページに移ると、公式プレイヤーになる。
- `/watch/{数字}`（チャンネル動画のスレッド ID の形式）は対象外（リンクのクリックも直接開くのも `sm`・`nm`・`so` のみ）。
- 直接開いた動画を閉じたとき（ページを離れるとき）の前回の再生位置は、最後に 5 秒おきに書いた位置になる。閉じる直前の再生とシークは記録されないことがある。
- 直接開いたとき、共通ヘッダーのログインの戻り先は `/nico-ext/watch/{id}` になる。
- 自動再生がブラウザに止められたときは一時停止のまま開く（再生ボタンか Space で再生する）。
- Dark Reader などの色を書き換える拡張は、オーバーレイの色を崩すことがある。nicovideo.jp を対象外にする。
