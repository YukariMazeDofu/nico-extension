# 要件

`nicovideo.jp` の動画を、公式プレイヤーの代わりに同じページの上のオーバーレイで再生する。

## 前提

- Chrome 専用の Manifest V3 拡張（Chrome 123 以上）。Chrome 固有の API を使ってよい。
- WXT（TypeScript・Vite）で Chrome 向けにだけビルドする。オーバーレイは `createShadowRootUi` で作る。
- ニコニコ動画にログインした状態で使う。ブラウザの Cookie をそのまま使う。未ログインでは投稿とニコるができない。
- 非公開。パッケージ化されていない拡張として読み込む。
- セグメントを保存しない。

## 機能

状態の意味は [README.md](../README.md#変更の流れ)。

| 区分 | 要件 | 状態 | 動作 |
| --- | --- | --- | --- |
| 起動 | `nicovideo.jp` 内の動画リンクをクリックすると、画面遷移せず同じページにオーバーレイで開く。閉じると元のページに戻る | 実装済み | [リンクのクリック](behavior.md#リンクのクリック) |
| 起動 | `/watch/{id}` を直接開いたとき（外部サイトのリンク、アドレスバー、ブックマーク、新しいタブ）も自作プレイヤーで開く。公式プレイヤーでも開ける | 実装済み | [直接開く](behavior.md#直接開く)・[公式で開く](behavior.md#公式で開く) |
| 起動 | 自作プレイヤーで開いた動画のリンクを訪問済みの見た目にする | 実装済み | [訪問済みにする](behavior.md#訪問済みにする) |
| 表示 | 上段にタイトル・投稿日時と各カウント・タグ、右側に投稿者・ジャンル・シリーズ・説明文。動画の枠は動画の縦横比に合わせる | 実装済み | [配置](behavior.md#配置)・[右パネル](behavior.md#右パネル) |
| 表示 | コントロールは動画の下に置き、動画に重ねて自動で隠す表示と切り替えられる | 実装済み | [コントロール](behavior.md#コントロール) |
| 表示 | ライト・ダークのテーマ。ライト・ダーク・OS の設定に合わせるを切り替え、既定は OS の設定に合わせる | 実装済み | [テーマ](behavior.md#テーマ) |
| 再生 | HLS 再生、画質選択、再生速度、音量、全画面、キーボードショートカット、ホイール | 実装済み | [コントロール](behavior.md#コントロール)・[操作](behavior.md#操作) |
| 再生 | トークンが切れたら取り直す。視聴イベントを送る | 実装済み | [watch-page.md](../niconico/watch-page.md#トークンの期限)・[heartbeat.md](../niconico/heartbeat.md) |
| コメント | 取得（owner・main・easy）と表示 ON/OFF | 実装済み | [コントロール](behavior.md#コントロール) |
| コメント | GPU 合成による描画。文字のラスタライズはコメント 1 件につき 1 回、毎フレームは位置の更新だけにする。配置と描画は層を分ける | 実装済み | [コメントの描画](architecture.md#コメントの描画) |
| コメント | 共有 NG レベル（無・弱・中・強） | 実装済み | [右パネル](behavior.md#右パネル) |
| コメント | シークバーの帯の色で盛り上がりを示す（強調の度合いを調整できる）。キャッシュ済みかどうかを帯の太さで示す | 実装済み | [シークバー](behavior.md#シークバー) |
| コメント | 投稿。自分の投稿は黄色の枠で囲む | 実装済み | [投稿欄](behavior.md#投稿欄) |
| コメント | 一覧（再生位置への自動スクロールを切り替えられる）とニコる・取り消し | 実装済み | [右パネル](behavior.md#右パネル) |
| コメント | 投稿者のニコスクリプト（`＠デフォルト`・`＠置換`・`＠逆`）を表示に反映する。`＠ジャンプ` は再生位置を移す。`＠シーク禁止`・`＠コメント禁止` は守らない | 保留（表示が崩れて困る動画が出たら着手する） | [ニコスクリプト](../niconico/comment-render.md#ニコスクリプト) |
| 非機能 | ニコニコの API を呼ぶ層を UI から分ける。状態を service worker に持たない | 実装済み | [構成](architecture.md) |

## 対象外

- Firefox。
- `nicovideo.jp` 以外のサイトでの再生。
- 連続再生（マイリスト・プレイリスト）。
- シークバーのサムネイル（ストーリーボード）。
- 公式の NG 設定との同期、拡張独自の NG リスト。
- かんたんコメントの投稿。
- 投稿のチャレンジ（Cloudflare Turnstile）。求められたら公式で開いて投稿する。
